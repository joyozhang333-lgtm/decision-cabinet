# 知识库治理

## 目标

知识库追求的不是“塞入最多文本”，而是让进入决策链的每一条知识都可追溯、可质疑、有限定条件。

## 卡片结构

每张卡必须包含：

- `领域`：decision / business / finance / management / wisdom；
- `传统`：china / international / universal；
- `标签`：支持本地检索；
- `摘要`：用自己的话概括，不复制受版权保护的长文；
- `关键问题`：把知识转成提问；
- `方法`：把知识转成动作；
- `边界`：说明它何时不适用、不能替代什么；
- `来源`：原始链接与来源类型。

## 来源分级

| 等级 | 典型来源 | 用法 |
| --- | --- | --- |
| Primary | 法定披露、监管文件、原始统计、经典原文、原始论文 | 关键事实首选 |
| Official | 标准组织、政府、交易所、作者或机构官网 | 方法和规则首选 |
| Research | 学术机构、同行评审综述 | 补充机制与争议 |
| Secondary | 高质量媒体与专业解释 | 只作线索，不替代关键原始证据 |

## 传统文化

- 经典原文、注释与现代应用必须分层。
- 不伪造“圣人说过”的句子。
- 不把某一现代解释写成经典的唯一原义。
- 不用传统文化替代事实核查、专业尽调和现代法律伦理。
- 《先知》等现代经典只做主题摘要；现代中文译本可能受版权保护，不复制全文。

## 金融知识

- 数据必须标记日期、报告期、口径与币种。
- 原始披露优先于公司宣传，公司宣传优先于媒体转述，媒体转述优先于社交传闻。
- “当前”与“最新”属于高漂移事实，未联网核验时必须写成待查证。
- 估值输出使用区间与敏感性，不制造单点精确。
- 个股结论必须放回仓位、相关性、流动性、期限与最大可承受损失。

## 更新与纠错

任何人都可以提交来源更正。修改知识卡时，PR 应说明：旧内容、问题、新来源、边界变化与受影响测试。高风险金融或法规内容应优先做小步、可审查更新。
