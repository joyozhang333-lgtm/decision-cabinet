01 / CAPABILITIES

不是更多意见，而是更完整的局面

系统把答案拆回决策结构，让你知道每个判断从哪里来、还缺什么、何时应该改变。

商

商业与经营

顾客价值、定价、单位经济、现金流、资本配置、增长、团队与组织承载力。

财

金融与股票

原始披露、三表、估值区间、仓位、流动性、周期、反证与退出条件。

生

人生重要转折

职业、城市、关系、责任与长期方向。看清你选择怎样的生活、承担什么代价。

02 / FOUR ROUNDS

不是四次回答，而是四轮交锋

每轮都有公开议题、回应关系和结构化纪要。没有新增信息时，讨论从既有分歧继续，而不是重播第一轮。

ROUND 01

事实定界

分开事实、推断与未知，列出各方观点、小结论、共识和非共识。

ROUND 02

聚焦争议

把非共识变成具体议题，让顾问点名支持、质疑或修正彼此。

ROUND 03

压力测试

检验代价、反证、二阶效应、最坏情景与改变立场的信号。

ROUND 04

条件式收束

说明什么条件下选什么，保留少数意见、行动和停止条件。

03 / MCP INTEGRATIONS

把决策内阁插入你常用的智能体

同一个默认只读、无状态的 MCP server，为不同宿主提供知识检索、离线决策地图、顾问视角与四轮议事协议。

C

Codex 与 Claude Code

仓库内置 plugin 与 stdio MCP 配置；CLI 入口已本机核对。外部模型凭证仍由用户自己管理。

H

DeepSeek 与 Hugging Face

提供 DeepSeek Harness、Hugging Face Tiny Agents，以及 ML Claw/OpenClaw MCP registry 预设；各宿主的验证状态单独标明。

W

腾讯 WorkBuddy

WorkBuddy 不等于 CodeBuddy。需自行部署带 HTTPS 与鉴权的 Streamable HTTP MCP；静态 Demo 不是远程后端。

04 / SAFETY

金融决策，先尊重证据和风险

系统不接实时行情时，就明确说不知道。它要求投资讨论标注数据时点、原始披露、估值假设、仓位与论点失效条件。

不伪造实时数据

A 股回到交易所或巨潮，美股回到 SEC EDGAR。传闻不进入估值基准。

不承诺收益

给区间、条件与反证，不给确定目标价，也不把单个标的脱离整个资产负债。

不替用户拍板

重大投资、法律、医疗和税务事项应核验原始资料并咨询持牌专业人士。

重要声明：Decision Cabinet 仅用于教育、思考与决策支持，不构成投资建议、证券推荐、法律意见、医疗建议或税务建议，也不保证任何结果。AI 可能出错、遗漏或使用过时信息。
